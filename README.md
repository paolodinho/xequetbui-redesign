# xequetbui.com - giao diện mới (bản demo)

Theme WordPress `icd-cleaning` cho ICD Cleaning Machines (xequetbui.com), giữ nguyên toàn bộ URL và SEO của site cũ.

- `wp/theme/icd-cleaning/`: theme
- `wp/mu-plugins/`: permalink `.html`, 301 xe điện, SEO, chế độ catalog (không giỏ hàng, không thanh toán)
- `wp/import.php`: nhập dữ liệu từ site cũ

Nhánh `gh-pages` là bản xem giao diện tĩnh (chỉ để xem: form báo giá và tìm kiếm không chạy). Không index Google.
